Cara memindahkan ke Figma

Buka layar di Chrome → jalankan plugin/ekstensi html.to.design → impor ke file Figma “CRM” → letakkan di halaman milik PIC. Setelah diimpor, rapikan auto-layout & jadikan komponen dari halaman Design System.
